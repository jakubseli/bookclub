# Bookclub frontend

React + Vite client for the Bookclub API.

## Run

1. Start the backend first (it listens on http://localhost:8080).
2. In this folder:

```bash
npm install
npm run dev
```

3. Open http://localhost:5173.

The API address defaults to `http://localhost:8080/api/v1`. To use another one, set `VITE_API_URL` in a `.env.local` file.
